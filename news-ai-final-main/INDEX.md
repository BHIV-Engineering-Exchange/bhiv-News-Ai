## 🎯 **QUICK COMMAND REFERENCE**

### Installation
```bash
npm install
```

### Configuration
```bash
cp .env.example .env
# Edit .env with your credentials
```

### Initialize Database
```bash
npm run seed-db
```

### Run Development Server
```bash
npm run dev
```

### Validate with Samples
```bash
npm run validate-samples
```

### Monitor System
```bash
curl http://localhost:3000/api/system/info
```

### Monitor Real-time
```bash
websocat ws://localhost:3001
```
