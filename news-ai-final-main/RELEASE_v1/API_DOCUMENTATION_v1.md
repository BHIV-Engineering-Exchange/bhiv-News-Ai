# API Documentation v1.0

- Base URLs
  - REST: http://localhost:3000
  - WebSocket: ws://localhost:3001
- Endpoints
  - GET /health
  - GET /api/system/info
  - POST /api/news
  - GET /api/news
  - GET /api/news/:id
  - GET /api/news/status/:status
  - POST /api/bhiv/process
  - POST /api/bhiv/stream
  - GET /api/processed/:id
  - GET /api/audio/:id
  - POST /api/feedback
  - GET /api/feedback/metrics
  - GET /api/categories
- Notes
  - CORS: set ALLOWED_ORIGINS
  - Auth: BHIV routes require BHIV_API_KEY
  - Errors: { success:false, error:string }
